# Polars Visual Lab

เว็บแอปพลิเคชันเชิงโต้ตอบ (Interactive Web Application) สำหรับการเรียนการสอนไลบรารี **Python Polars** ควบคู่กับการทบทวนพื้นฐานภาษา Python พัฒนาขึ้นสำหรับนักเรียนระดับชั้นมัธยมศึกษาปีที่ 5 สาขาเทคโนโลยี โรงเรียน มอ.วิทยานุสรณ์

---

## วัตถุประสงค์ของโครงการ

1. ส่งเสริมความเข้าใจในการจัดการและวิเคราะห์ข้อมูลด้วยไลบรารี Python Polars ผ่านการแสดงผลตารางข้อมูลแบบเคลื่อนไหว (Visual DataFrame Animation)
2. เชื่อมโยงความรู้พื้นฐานภาษา Python ที่จำเป็นเข้ากับการเขียนคำสั่ง Polars ได้อย่างเป็นระบบ
3. นำเสนอสื่อการเรียนรู้ที่มีโครงสร้างชัดเจน อ่านง่าย และสามารถสืบค้นคำสั่งรวมถึงพารามิเตอร์สำคัญได้อย่างสะดวก โดยอ้างอิงโครงสร้างคำสั่งจากซอร์สโค้ดทางการของ Polars

---

## ความสามารถหลักของระบบ

### 1. ระบบแนะนำการใช้งานและข้อมูลผู้จัดทำ
- **หน้าต่างต้อนรับและข้อมูลผู้จัดทำ (`WelcomeModal`):** แสดงเมื่อเข้าสู่ระบบครั้งแรก และสามารถเปิดดูซ้ำได้จากส่วนท้ายของหน้าเว็บ
- **คู่มือการใช้งาน (`GuideModal`):** อธิบายขั้นตอนการใช้งานเว็บไซต์เป็นลำดับขั้นตอน สามารถเปิดดูได้ตลอดเวลาจากแถบนำทางด้านบน

### 2. โมดูลทบทวนพื้นฐานภาษา Python (`PythonBasicsView`)
นำเสนอเนื้อหาพื้นฐานที่เกี่ยวข้องกับการใช้งาน Polars ในรูปแบบการ์ดเชิงโต้ตอบ จำนวน 4 หัวข้อ ได้แก่
- **ตัวแปรและชนิดข้อมูล (Variables):** `int`, `float`, `str`, `bool` และ `list`
- **ตัวดำเนินการ (Operators):** การคำนวณทางคณิตศาสตร์และการเปรียบเทียบเงื่อนไข
- **ความแตกต่างระหว่างฟังก์ชันและเมธอด (Function vs. Method):** การเรียกใช้ผ่านโมดูล (`pl.`) เทียบกับการเรียกใช้ผ่านอ็อบเจกต์ตาราง (`df.`)
- **การส่งค่าและรับค่าพารามิเตอร์ (Arguments, `*args`, `**kwargs`):** การส่งค่าแบบระบุตำแหน่ง การระบุชื่อ และการรับค่าหลายรายการ

### 3. โมดูลคลังคำสั่ง Python Polars (`PolarsExplorer` และ `DataFrameVisualizer`)
- **ระบบค้นหาและจำแนกหมวดหมู่:** รองรับการค้นหาทั้งชื่อคำสั่งภาษาอังกฤษและคำสำคัญภาษาไทย พร้อมรายการแนะนำอัตโนมัติ (Autocomplete) และป้ายกรองตามหมวดหมู่
- **รายละเอียดคำสั่งและตัวอย่างโค้ด:** แสดงประเภทของคำสั่ง (`Function`, `Method`, `Expression`), รูปแบบคำสั่ง (Signature), คำอธิบายพารามิเตอร์ที่สำคัญ และตัวอย่างโค้ดพร้อมปุ่มคัดลอก
- **คลังคำสั่งครอบคลุม 18 คำสั่งหลัก:**
  - การนำเข้าข้อมูล: `pl.read_csv()`
  - การสำรวจข้อมูลเบื้องต้น: `df.head()`, `df.describe()`
  - การเลือกคอลัมน์: `pl.col()`, `df.select()`
  - การกรองข้อมูล: `df.filter()`
  - การเพิ่มและแก้ไขคอลัมน์: `df.with_columns()`
  - การจัดการค่าว่าง: `df.drop_nulls()`, `df.fill_null()`, `pl.coalesce()`
  - การจัดการข้อมูลซ้ำ: `df.unique()`
  - การเรียงลำดับและจัดกลุ่ม: `df.sort()`, `df.group_by()`
  - การรวมตาราง: `df.join()`, `pl.concat()`
  - การสร้างเงื่อนไข: `pl.when()`
  - การแปลงชนิดข้อมูล: `.str.to_date()`, `.cast()`
- **ตารางจำลองผลลัพธ์แบบเคลื่อนไหว:** แสดงการเปลี่ยนแปลงของข้อมูลตามประเภทคำสั่ง (`filter_rows`, `drop_nulls`, `add_column`, `deduplicate`, `sort_rows`, `transform_values`, `select_col`) พร้อมปุ่มสั่งทำงานและรีเซ็ตข้อมูล
- **มาสคอตผู้ช่วย (`PolarsMascot`):** ภาพประกอบเวกเตอร์แบบกำหนดเองพร้อมกล่องข้อความคำแนะนำที่ปรับเปลี่ยนตามบริบทการใช้งาน

## การติดตั้งและเริ่มต้นใช้งาน

### ความต้องการของระบบ
- Node.js เวอร์ชัน 18 ขึ้นไป
- npm

### ขั้นตอนการติดตั้งและรันเซิร์ฟเวอร์พัฒนา

```bash
# 1. คัดลอกคลังซอร์สโค้ด
git clone https://github.com/peelaphat/Polars_Visual_Lab.git
cd Polars_Visual_Lab

# 2. ติดตั้งแพ็กเกจที่จำเป็น
npm install

# 3. เริ่มต้นเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

### คำสั่งสำหรับการสร้างไฟล์เพื่อนำไปใช้งานจริง (Production Build)

```bash
npm run build
npm run preview
```
